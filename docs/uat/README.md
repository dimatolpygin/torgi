# Чек-листы проверки (UAT)

Здесь лежат короткие чек-листы **для человека** — по одному на этап Вехи 3
(`ext-0.md`, `ext-1.md`, …). Их пишет Claude в конце сессии этапа, проходит человек.

**Правило файла:** не больше 5 пунктов, простым языком, каждый пункт — «что сделать →
что должно быть видно». Никакого жаргона, никаких «убедиться, что модуль корректно
инициализируется».

Пока чек-лист этапа не пройден человеком — тег `ext-N-done` не ставится, следующий этап
не берётся.

## Шаблон

```markdown
# Проверка: этап ext-N — <название>

Займёт ~N минут. Нужно: <ПК с Chrome / ничего / боевая ночь>.

- [ ] <что сделать> → должно быть видно: <что именно>
- [ ] ...

**Что я НЕ смог проверить сам и почему:** <честно: требует ПК клиентки / живой ночи / решения>

Если что-то не так — напиши, что именно ты увидел.
```
